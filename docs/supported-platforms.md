# Supported platforms

One Brain packages and supports these desktop targets:

| Operating system | Architecture | Package |
| --- | --- | --- |
| Linux | x64 | AppImage |
| Windows | x64 | NSIS installer |
| macOS | Apple Silicon (arm64) | DMG |

Intel macOS (x64) is not supported because the installed `onnxruntime-node` runtime does not include a `darwin/x64` native binding. Windows arm64 files are present in the dependency, but Windows arm64 is not currently built or listed as a supported target.
