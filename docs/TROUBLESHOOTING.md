# Troubleshooting

## Embedding model does not load

The first semantic search may download about 130 MB for the pinned multilingual MiniLM model. Connect to the internet and choose **Retry** beside **OB-EMBED-001**. The status Details section includes a sanitized error name, message, and stack. Model download is not performed during build. If the cache is damaged or incomplete, retry after checking disk space and connectivity.

## AppImage will not start on Ubuntu

Some Ubuntu installations need `libfuse2` to mount AppImage files. Install the compatible FUSE 2 runtime for your Ubuntu release, or extract the AppImage with its supported `--appimage-extract` option. The exact package name can vary by Ubuntu version.

## Wayland graphics or restart behavior

On Linux Wayland, One Brain may re-launch using the X11 Ozone backend if `DISPLAY` indicates XWayland is available. This requires XWayland. Set `ONE_BRAIN_OZONE=auto` to skip the early re-launch while collecting logs; this allows Electron's automatic backend selection and may reproduce a Wayland-only graphics crash. For Quick Context, Wayland may also require assigning the displayed command in desktop keyboard-shortcut settings.

## AI client cannot connect

- Confirm One Brain is running and unlocked. Locked MCP requests are denied.
- Use **Settings → Connections** to test the client and review its configuration preview.
- If a client is pending, approve it in One Brain. If authentication fails, revoke and reconnect it from Connections rather than copying token files manually.
- The MCP or proxy service may select a different loopback port if its default is busy; use the endpoint and bridge generated by the app.

## Browser extension is disconnected or degraded

Open the extension popup, check the selected site's status and host permission, and verify One Brain is running. Pair again if the token is missing, revoked, or the origin changed. Approve the extension client in One Brain. A site update can break composer or message selectors; the extension status reports when context insertion is unavailable.

## Installer warning or unsupported system

Installers are unsigned, so SmartScreen or Gatekeeper can display a warning. Linux AppImage, Windows x64, and Apple Silicon macOS are the supported release targets. Intel macOS is unsupported because the installed ONNX Runtime package lacks `darwin/x64`.
